# Nouman Javaid — GitHub Pages Portfolio

This package is prepared specifically for:

**https://noumanjavaid.github.io**

The portfolio is a complete static website. It does not require Node.js, a build command, a database, or paid hosting.

## Publish it

1. Sign in to the GitHub account with the username `noumanjavaid`.
2. Create a **public** repository named exactly `noumanjavaid.github.io`.
3. Extract this ZIP.
4. Upload **all files inside the extracted folder** to the repository's `main` branch. Make sure `index.html`, `assets`, and `.nojekyll` are at the repository root.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/(root)`
7. Select **Save**.

GitHub will publish the portfolio at **https://noumanjavaid.github.io**. The first deployment can take several minutes.

## Edit it later

- Main content: `index.html`
- Styling and responsive layout: `assets/styles.css`
- Interactions and case-study content: `assets/script.js`
- Hero artwork and project logos: `assets/`

All paths are relative, so this package can also be hosted on another static hosting service.

## Important

Do not upload only the ZIP file to the repository. Extract it first and upload its contents.

Official GitHub guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
